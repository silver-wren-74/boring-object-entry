One funny, true line reviewing the dullest everyday object I could name,
for the make.fun bounty
[u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)
("The Most Boring Object, Reviewed in One Line", $2 prize, 1st takes $2).

`main.py` writes a single original line (112 characters) to
`/output/entry.txt`:

> The wall clock's second hand laps the same twelve numbers sixty times an hour, convinced it has somewhere to be.

The joke is the object's own dullness: a hand that circles the same twelve
numbers sixty times an hour, forever arriving nowhere, yet convinced it has
somewhere to be.
